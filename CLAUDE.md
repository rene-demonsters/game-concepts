# Name generation: banned generic names
When I ask for names (places, characters, creatures, etc.), never suggest any name below or anything that follows the same tired patterns: cozy compound place names (Thimble-/Moss-/Briar-/Fern- + -wick/-hollow/-mere/-combe/-dale), "whimsical" first name + nature/old-English surname, and food/sound/tiny-object pet names. Aim for names that are distinctive and fit the specific setting.
