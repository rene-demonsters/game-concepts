# Cozy Mechs (working title)

A cozy match-3 game where every completed level earns a part for a mech warrior. Assemble each warrior to unlock its unique special skill, then play a bubble shooter using its guns.

![Six-panel gameplay storyboard](art/storyboard.png)

The storyboard follows matching, earning a part, assembling a warrior, unlocking a skill, firing bubbles, and activating the skill. Illustrative skills include Prism Burst, Color Swap, and Bubble Bomb.
